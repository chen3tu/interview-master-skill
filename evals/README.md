# Behavioral evaluation

Cases are synthetic. E01–E28 cover the agreed behavior categories; L01–L08 add multilingual and localization checks. Run using the skill and case input, retaining actual output. No expected answer should be supplied to the performing model.

Record skill version, model/session, tool limits, actual outputs and observed findings. This suite is not a unit test and no keyword matcher proves behavior. Some cases include scripted candidate replies; these are test inputs, not real interview observations. Batch execution in a shared evaluator context is a limitation and must be recorded.

Baseline comparison uses equivalent inputs and separate execution context where possible. Critical facts, language switching and pauses require attention. Structure tests, package tests and live-host installation are separate checks. Never label an unrun case passed.

Release rubric: no fabricated personal facts/sources, no unwanted blocking intake, correct pause behavior, no double counting, actual requested answer bodies, and no loss of direct salary/offer routes. Judge role-specificity, professional method, usable outputs and evidence on the 0–3 anchors in the plan.
