# Migrating to v4 / v4迁移

Development candidate: 4.0.0-rc.2. Keep installation name interview-master.

## What changes
Preparation no longer globally requires one-question-at-a-time intake. Complete mode creates a usable draft first; mock mode remains sequential. Facts are reused and checked in batches. Role modules use worked samples; mock feedback separates coverage from performance.

Language settings independently control coaching, answers and mock dialogue. Existing Chinese users can continue in Chinese; English and mixed-language requests need no separate installation.

## Preserve candidate work
Keep existing résumés, submitted versions, facts, stories and sessions outside the skill folder. Do not overwrite them with new examples or state templates. Treat old generated answers as unverified drafts until their historical claims have support.
Use a continuation summary to transfer target, settings, known facts, unresolved items, actual observations and next action. Do not force users to re-enter all history.

## References
The old 19 reference paths remain. Product content has its own module; the old product/operations path focuses on operations and links product. Technical and management paths route to appropriate specialties/career stages. New runtime examples live under references/examples and are bundled.

## Install and validate
Back up the previous skill package. Install the complete candidate folder/ZIP in a supported host, then try one preparation request and one mock with a pause and language switch. Verify that references load and user data remains untouched. Check the release validation report for actual host coverage.

## Rollback
Replace only the skill installation with the prior package. Retain candidate data and recent drafts; do not reverse-migrate by deleting facts or edited documents. If a new draft conflicts with a submitted résumé, preserve both and explain the discrepancy.

## Host selection

Use the same package in supported Agent Skills hosts. Codex is the acceptance host selected by the maintainer; Claude is not a mandatory release gate. See [compatibility](compatibility.md) and [Codex acceptance](../evals/reports/codex-acceptance.md). WorkBuddy/Claude live checks are separate from format portability.
