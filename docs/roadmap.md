# Roadmap

v4 candidate implements preparation modes, evidence boundaries, role work samples, adaptive simulation and multilingual preferences. Completion/validation is tracked separately; planned work is not a claim of release.

Next priorities should follow reproducible feedback:
1. Any fabrication, unwanted blocking intake, language/ownership change or lost state.
2. Demonstrated role-depth gaps and model/host regressions.
3. Independent language review and additional language/market test cases.
4. Deeper sales, customer success, design, finance and consulting modules with full work samples.

A web application, account system or real-time voice evaluation is not assumed. No automatic monitoring or reminders are configured by this roadmap.

Useful feedback: mode, target role, language settings, host, synthetic prompt, observed behavior and expected outcome. Do not provide a full résumé or private interview transcript.
