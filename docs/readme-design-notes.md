# 项目说明升级依据

2026-10-20核对 GitHub 项目页及 README。以下星数是页面显示的近似快照，只用于挑选文档参考，不代表本项目质量，也不保证这些项目的方法适合面试训练。

| 参考项目 | 星数快照 | 观察到的组织方式 | 本项目采用 |
|---|---:|---|---|
| [obra/superpowers](https://github.com/obra/superpowers) | 302.2k | 先说明工作方式，按宿主分安装，提供排错与更新入口 | 多Agent兼容表、分宿主安装、更新与常见问题 |
| [anthropics/skills](https://github.com/anthropics/skills) | 182.2k | 解释Skill是什么、展示目录、区分格式规范与具体平台 | 一句话定位、最小包结构、标准与运行验证分开 |
| [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) | 32.7k | 按使用场景说明能力与触发请求 | 可复制提示词、岗位与产物表、直接进入具体任务 |

独立重写了中英文介绍，没有复制第三方正文、徽标或示意图。首页优先回答：解决什么问题、在哪用、怎样开始、会得到什么、验证到了哪一步、如何反馈。原有21项目的面试机制调研见[来源笔记](source-notes.md)。

首页不使用尚未发布的版本下载承诺，不拿main分支CI徽章冒充候选包验收，也不将本地演示称为真人面试成功率。
