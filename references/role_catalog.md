Select from JD responsibilities, not a title alone. Load the relevant module plus shared data or career-stage guidance only when needed. User-facing language follows [language preferences](language_and_locale.md).

Technical subdirections: [backend](role_backend.md), [frontend](role_frontend.md), [mobile](role_mobile.md), [AI application engineering](role_ai_application.md). Shared: [data](role_data.md), [early career/transition](early_career_and_transition.md), [case practice](case_study_guide.md).

These are authored modules with worked examples; behavioral validation status is documented in the repository evaluation report, not implied by this catalogue. They do not cover every specialty in each field. Sales, design, finance, consulting and other roles can use the JD method with explicitly provisional criteria; do not claim a dedicated deep module exists.

Domain overlays (finance, health, manufacturing, etc.) apply only when the JD requires them. Verify material specialized facts. Do not import a personal finance case into unrelated careers.
